# Рев’ю PR-1

## Знахідки

### [medium] Перша сторінка пропускає початкові позики

- **Правило:** Пагінація має повертати записи запитаної сторінки; тести мають перевіряти конкретний результат.
- **Файл і рядок diff:** `app/src/loans.js:12`
- **Умова:** Виклик `listLoansPage` із типовими параметрами або `page: 1`.
- **Наслідок:** `start` дорівнює `pageSize`, тому перші `pageSize` записів пропускаються. Якщо позик менше за розмір сторінки, перша сторінка порожня. Доданий тест у `app/test/loans.test.js:37–41` перевіряє лише метадані, а не `items`, тож не виявляє дефект.
- **Напрям виправлення:** Для нумерації сторінок від 1 обчислювати зсув як `(page - 1) * pageSize` і перевірити в тестах записи першої та наступної сторінок.

### [medium] Розмір сторінки не обмежений

- **Правило:** Списки з необмеженою кількістю записів мають пагінацію з верхньою межею розміру сторінки.
- **Файл і рядок diff:** `app/src/loans.js:10, 13`
- **Умова:** Викликач передає дуже велике значення `pageSize`.
- **Наслідок:** Функція повертає скільки завгодно записів за один виклик, що нівелює обмеження розміру сторінки й може створити надмірне навантаження на відповідь.
- **Напрям виправлення:** Валідувати `page` і `pageSize` як додатні цілі числа та встановити й застосовувати максимальний `pageSize`.

### [low] Новий публічний API не внесено до журналу змін

- **Правило:** Зміни публічного API мають бути відображені в `app/CHANGELOG.md`.
- **Файл і рядок diff:** `app/src/loans.js:10` — додано експортовану функцію `listLoansPage`; відповідного запису в `app/CHANGELOG.md` немає.
- **Умова:** PR додає нову експортовану функцію.
- **Наслідок:** Журнал змін не документує новий публічний API.
- **Напрям виправлення:** Додати до `app/CHANGELOG.md` запис про сигнатуру та результат `listLoansPage`.
