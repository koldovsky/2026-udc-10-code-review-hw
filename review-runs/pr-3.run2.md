**Вердикт:** BLOCK

## Що заявляє PR
Додає `exportMembersCsv` — CSV усіх учасників (ім'я, email, телефон, роль) для щомісячної звірки.
- «експорт учасників у CSV: ім'я, email, телефон, роль»
- «Без користувача — відмова, як і скрізь»
- «Тест на формат файлу додав»

## Знахідки

### 1. [critical] [R1, R9] Будь-який учасник вивантажує контакти всіх; тест на відмову — лише для анонімного
- **Де:** `app/src/members.js:+11-12` (диф, рядки 25–26); `app/test/members.test.js:+43-45` (диф, рядки 60–62)
- **Цитата:** `if (!user) throw new AccessDenied();`
- **Чому це проблема:** перевіряється, що користувач є, а не що він — персонал. Сусідні `listMembers` (`requireRole(user, STAFF)`) і `memberCard` (лише власна картка для учасника) суворіші. З дифом: `exportMembersCsv(db, { id: 1, role: "member" })` повертає email і телефони всіх учасників. Тест `assert.throws(() => exportMembersCsv(createDb(), null), AccessDenied)` не покриває саме цей випадок.
- **Як виправити:** `requireRole(user, STAFF)` (або `["admin"]`) + `assert.throws(() => exportMembersCsv(createDb(), olya), AccessDenied)`.
- **Впевненість:** висока

### 2. [high] [R2] Email і телефони всіх учасників віддаються без журналу доступу
- **Де:** `app/src/members.js:+14` (диф, рядок 28)
- **Цитата:** `const lines = db.members.map((m) => [m.id, m.name, m.email, m.phone, m.role].join(","));`
- **Чому це проблема:** домовленість 2 — запис `logAccess` на кожного учасника, чиї дані віддано. З дифом після експорту `db.accessLog.length === 0`.
- **Як виправити:** `for (const m of db.members) logAccess(db, user, m.id, "members-csv-export");` + тест на журнал.
- **Впевненість:** висока

### 3. [medium] [R15] Поля CSV не екрануються (коми, лапки, формули)
- **Де:** `app/src/members.js:+14` (диф, рядок 28)
- **Цитата:** `[m.id, m.name, m.email, m.phone, m.role].join(",")`
- **Чому це проблема:** ім'я з комою чи лапками зсуває колонки; значення на `=`, `+`, `-`, `@` Excel виконає як формулу (CSV injection). Імена вводять самі учасники — вхід недовірений.
- **Як виправити:** брати поля в лапки з подвоєнням `"`; для значень на `= + - @` — префікс `'`; тест з комою й лапками в імені.
- **Впевненість:** середня

### 4. [low] [R6] Запис у CHANGELOG не описує контракт
- **Де:** `app/CHANGELOG.md:+8` (диф, рядок 11)
- **Цитата:** `` - `exportMembersCsv(db, user)` — CSV of members for the monthly reconciliation. ``
- **Чому це проблема:** запис є, але без колонок (з персональними даними), ролі доступу й журналу — сусідній запис `overdueReport` це вказує.
- **Як виправити:** «staff-only; returns CSV `id,name,email,phone,role`; each exported member is recorded in the access log».
- **Впевненість:** середня

### 5. [low] [R8] Тест формату можна посилити
- **Де:** `app/test/members.test.js:+36-41` (диф, рядки 53–58)
- **Цитата:** `assert.equal(lines[0], "id,name,email,phone,role");` / `assert.equal(lines.length, 6);`
- **Чому це проблема:** тест перевіряє конкретні значення (заголовок, кількість), тож це не «не тест»; порада — додати перевірку хоча б одного рядка даних.
- **Як виправити:** `assert.equal(lines[1], "1,Оля Приклад,olya@example.invalid,+380000000001,member")`.
- **Впевненість:** висока
