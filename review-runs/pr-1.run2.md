## Знахідки

### 1. [high] [R15, R8] Сторінка 1 повертає другу сторінку; тест цього не бачить
- **Де:** `app/src/loans.js:+31` (диф, рядки 10–12); `app/test/loans.test.js:+15-20` (диф, рядки 36–41)
- **Цитата:** `export function listLoansPage(db, user, { page = 1, pageSize = 20 } = {}) {` … `const start = page * pageSize;`
- **Чому це проблема:** нумерація з 1, зсув — як для нумерації з 0. Бібліотекар, що відкриває першу сторінку: `{ page: 1, pageSize: 3 }` → id `[4, 5, 6]` замість `[1, 2, 3]`; виклик за замовчуванням при 7 позиках → `items: []`. Перша сторінка недосяжна. Новий тест перевіряє лише `total`, `page`, `pageSize` (відлуння аргументів) і лишається зеленим при цьому дефекті.
- **Як виправити:** `const start = (page - 1) * pageSize;` + `assert.deepEqual(res.items.map((l) => l.id), [1, 2, 3])` для першої сторінки й перевірка останньої неповної.
- **Впевненість:** висока

### 2. [medium] [R7, R15] `page` і `pageSize` не валідуються й не обмежуються
- **Де:** `app/src/loans.js:+31-34` (диф, рядки 10–13)
- **Цитата:** `{ page = 1, pageSize = 20 } = {}` … `all.slice(start, start + pageSize)`
- **Чому це проблема:** вхід контролює клієнт: `pageSize: 1_000_000` повертає весь список за раз (сторінкування не захищає від проблеми, заради якої PR), `page: -3`/`0`/дробові значення приймаються як є — `slice` з від'ємним `start` віддає хвіст списку.
- **Як виправити:** `MAX_PAGE_SIZE` (напр. 100); `Number.isInteger(page) && page >= 1`, `Number.isInteger(pageSize) && 1 <= pageSize <= MAX_PAGE_SIZE`, інакше помилка.
- **Впевненість:** висока

### 3. [low] [R6] Нова публічна функція без запису в `app/CHANGELOG.md`
- **Де:** `app/src/loans.js:+30` (диф, рядок 10); `app/CHANGELOG.md` у дифі не змінено
- **Цитата:** `export function listLoansPage(db, user, { page = 1, pageSize = 20 } = {}) {`
- **Чому це проблема:** домовленість 6 («Нова функція — теж зміна»). Блокує за домовленістю; серйозність low, бо це ловить детермінована CI-перевірка.
- **Як виправити:** запис `listLoansPage(db, user, { page, pageSize })` → `{ items, page, pageSize, total }`, сторінки з 1.
- **Впевненість:** висока

### 4. [low] [R18] JSDoc «for the staff UI» неточний
- **Де:** `app/src/loans.js:+29` (диф, рядок 9)
- **Цитата:** `/** Paged variant for the staff UI: { items, page, pageSize, total }. */`
- **Чому це проблема:** функцію може викликати й учасник (бачить лише свої позики, як у `listLoans`) — поведінка коректна, коментар вводить в оману.
- **Як виправити:** «Staff see every loan; a member sees only their own — paged.»
- **Впевненість:** висока
