# Рев'ю PR-4: Винести хелпери дат у src/dates.js

## Знахідки

### 1. Запис у CHANGELOG не відповідає фактичному API: `toUtcMs` — нова публічна функція, а не перенесена, і її сигнатура не вказана
- Правило: #6 — Зміна того, що публічна функція в `src/` приймає або повертає, — запис у `app/CHANGELOG.md`, який збігається з фактичною сигнатурою
- Рівень: блокує
- Впевненість: висока
- Де: `app/CHANGELOG.md:8` (диф, рядок 11); `app/src/dates.js:6` (диф, рядок 27)
- Доказ: `` - `src/dates.js` — date helpers moved here from `loans.js` (`toUtcMs`, `daysBetween`, `addDays`) `` і `export function toUtcMs(iso) {`
- Чому це проблема: у базовому `app/src/loans.js:8` був лише приватний `function toUtc(iso)` без `export`. Тобто `toUtcMs` — нова публічна функція з новою назвою, а не перенесена. Запис подає її як перенесену з `loans.js`. Ні параметрів (`iso`), ні форми результату (число мілісекунд від epoch в UTC) він не називає. Прийнятий у цьому CHANGELOG формат для нових функцій саме такий: `` `overdueReport(db, user, todayIso)` — … with `loanId`, `member`, … ``. Неповний запис — це порушення.
- Що зробити: додати окремий запис про нову функцію, наприклад `` `toUtcMs(iso)` — new: returns the UTC timestamp in ms for a `YYYY-MM-DD` string (previously private `toUtc` in `loans.js`) ``. Для `daysBetween(fromIso, toIso)` → ціле число днів і `addDays(iso, days)` → рядок `YYYY-MM-DD` вказати сигнатури. Окремо зазначити, що `loans.js` реекспортує лише `daysBetween` і `addDays`.

### 2. Опис PR не згадує, що з'явилась нова публічна функція
- Правило: #10 — Опис PR відповідає коду
- Рівень: блокує
- Впевненість: низька — потрібне рішення людини
- Де: `review-queue/pr-4/PR.md:3-5`; `app/src/dates.js:6` (диф, рядок 27)
- Доказ: `хелпери дат переїхали в окремий модуль`, `Перейменував пару змінних для ясності`, `Поведінка не змінюється.`
- Чому це проблема: поведінка справді не змінилась: `lateFee`, `borrow`, `overdueReport` рахують так само, як раніше. Але PR робить більше, ніж «перейменував пару змінних». Він перейменовує приватну функцію `toUtc` на `toUtcMs` і відкриває її як публічне API модуля `dates.js`. Про розширення публічного API опис мовчить. Чи вважати це «зміною, про яку опис мовчить», чи це покрито словами «хелпери переїхали», має вирішити людина.
- Що зробити: дописати в `PR.md`, що `toUtcMs(iso)` (раніше приватна `toUtc`) тепер експортується з `src/dates.js`. Або не експортувати її, якщо публічною вона бути не має.
