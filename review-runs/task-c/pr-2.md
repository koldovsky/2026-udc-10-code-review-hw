# Рев’ю PR-2

Знайдено **4 підтверджені проблеми**.

1. **[P1] Email повертається без запису в журнал доступу**  
   **Правило:** кожне повернення email або телефону учасника має фіксуватися через `logAccess` для цього учасника.  
   **Місце:** `app/src/loans.js`, рядок 54 у diff — `email: db.findMember(l.memberId)?.email ?? null`.  
   **Умова:** коли звіт містить прострочений запис, функція повертає email відповідного учасника.  
   **Наслідок:** читання персональних даних не потрапляє до `accessLog`, тож аудит доступу до email неповний.  
   **Виправлення:** отримати учасника, записати доступ через `logAccess(db, user, member.id, purpose)` і повертати email із цього запису.

2. **[P2] Для кожного рядка учасника шукають двічі лінійним пошуком**  
   **Правило:** не створювати повторні лінійні пошуки у циклі, якщо це призводить до `O(n*m)` на великих колекціях.  
   **Місце:** `app/src/loans.js`, рядки 53–54 у diff — окремі виклики `db.findMember(l.memberId)`.  
   **Умова:** звіт обробляє `n` прострочених позик, а `findMember` сканує колекцію з `m` учасників.  
   **Наслідок:** пошук учасника для кожного рядка додає роботу порядку `O(n*m)`.  
   **Виправлення:** знайти учасника один раз для кожної позики або заздалегідь побудувати індекс учасників за ID.

3. **[P2] Додано текстову суму до API-відповіді**  
   **Правило:** гроші в API мають передаватися цілими копійками.  
   **Місце:** `app/src/loans.js`, рядок 57 у diff — поле `feeText`.  
   **Умова:** кожен рядок звіту містить форматовану суму в гривнях як рядок, поряд із `feeKopecks`.  
   **Наслідок:** клієнти API отримують суму також у локалізованому текстовому форматі, який не відповідає правилу цілочисельного представлення грошей.  
   **Виправлення:** залишити в API лише `feeKopecks`, а форматування для показу виконувати на стороні інтерфейсу.

4. **[P2] Не оновлено CHANGELOG після зміни публічного результату**  
   **Правило:** зміни приймання або повернення публічних функцій мають бути внесені до `app/CHANGELOG.md`.  
   **Місце:** зміни `overdueReport` у `app/src/loans.js`; `app/CHANGELOG.md` у diff відсутній.  
   **Умова:** функція тепер повертає поля `email` і `feeText`, яких немає в описі її результату в changelog.  
   **Наслідок:** задокументована форма відповіді не відповідає фактичній, що ускладнює використання й супровід API.  
   **Виправлення:** додати до changelog запис про нові поля, узгодивши опис із прийнятим контрактом API.

Окремо: опис PR згадує додавання імені та email, але не згадує `feeText`, яке також змінює публічну відповідь.
