# Рев’ю PR-6

## Знахідки

### [P1] Ім’я файлу може вивести читання за межі `uploads/`

- **Правило:** використовувати безпечні користувацькі шляхи.
- **Файл/рядок:** `app/src/imports.js:17`
- **Умова:** якщо `fileName` містить `../` або `..\`, `path.join(uploadDir, fileName)` може вказати на файл поза каталогом завантажень.
- **Наслідок:** імпортер читає сторонній локальний файл і обробляє його вміст як CSV.
- **Напрям виправлення:** відхиляти абсолютні шляхи й сегменти переходу до батьківського каталогу; після нормалізації перевіряти, що шлях лишається всередині `uploadDir`.

### [P2] Рядки CSV приймаються без перевірки обов’язкових полів і формату

- **Правило:** імпорт перевіряє обов’язкові поля й формат.
- **Файл/рядок:** `app/src/imports.js:18, 21–22`
- **Умова:** CSV містить порожнє ім’я, відсутній email чи телефон або некоректний формат значення.
- **Наслідок:** імпортер додає неповні чи некоректні записи до `db.members` і зараховує їх як успішний імпорт.
- **Напрям виправлення:** перевіряти кількість полів, обов’язковість і формат кожного значення до додавання запису; визначити поведінку для некоректних рядків.

### [P2] Читання контактних даних не журналюється

- **Правило:** журналювати доступ до email і телефону через `logAccess` для кожного учасника.
- **Файл/рядок:** `app/src/imports.js:21–22`
- **Умова:** функція читає email і телефон із кожного рядка та додає ці дані до бази.
- **Наслідок:** доступ до персональних контактних даних імпортованих учасників не відображається в журналі аудиту.
- **Напрям виправлення:** викликати `logAccess` для кожного імпортованого учасника з відповідною метою.

### [P2] ID може повторитися після видалення учасника

- **Правило:** ID лишаються унікальними після видалень.
- **Файл/рядок:** `app/src/imports.js:22`
- **Умова:** з `db.members` видалено учасника, але записи з більшими ID залишилися. Наприклад, після видалення учасника з ID `2` у початковому наборі `length + 1` дасть ID `5`, який уже є.
- **Наслідок:** у базі з’являться учасники з однаковим ID; пошук через `findMember` може повертати не того учасника.
- **Напрям виправлення:** виділяти ID монотонним лічильником або обирати ID, якого ще немає серед учасників.
