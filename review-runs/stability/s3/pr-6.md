## Знахідки

### 1. [critical] Ім'я файлу від користувача без нормалізації дозволяє читати файли поза `uploads/` — правило 3 (також 8)
- **Де:** `app/src/imports.js:18`
- **Цитата:**
  ```js
  export async function importMembersFromUpload(db, user, fileName, { uploadDir = UPLOAD_DIR } = {}) {
    requireRole(user, ["admin"]);
    const text = await readFile(path.join(uploadDir, fileName), "utf8");
  ```
- **Чому це проблема:** `fileName` — це ім'я, під яким користувач завантажив файл (так сказано в PR.md). Без перевірки воно йде просто в `path.join`. Ім'я на кшталт `../../etc/passwd` або `../app/src/db.js` виходить за межі `uploads/`. Функція читає будь-який файл, до якого має доступ процес, і заносить його рядки в `db.members` як учасників. Тести перевіряють лише звичайне ім'я файлу.
- **Як виправити:** Взяти `const full = path.resolve(uploadDir, fileName)` і кидати помилку, якщо `path.relative(path.resolve(uploadDir), full)` починається з `..` або є абсолютним шляхом. Інший варіант — дозволяти лише `path.basename(fileName) === fileName`. Додати тест, де `"../secret.csv"` відхиляється.

### 3. [medium] Некоректні рядки CSV тихо стають учасниками; id беруться з довжини масиву — правило 15
- **Де:** `app/src/imports.js:22`
- **Цитата:**
  ```js
  for (const row of rows) {
    const [name, email, phone] = row.split(",");
    db.members.push({ id: db.members.length + 1, name, email, phone, role: "member" });
  ```
- **Чому це проблема:** Порожній рядок у середині файлу дає учасника з `name: ""`, `email: undefined` і `phone: undefined`. Рядок із комою в лапках (`"Іваненко, Олена",…`) зсуває поля. Дублікати наявних email не перевіряються, і `added` рахує все це як успіх. `id: db.members.length + 1` дає дублікати id, якщо id у `members` не йдуть підряд від 1. Сусідній `db.addLoan` для цього тримає окремий лічильник.
- **Як виправити:** Пропускати або відхиляти рядки без імені чи email, обрізати пробіли й повертати список відхилених рядків. Id рахувати як `Math.max(...ids) + 1`, а краще додати `db.addMember` з власним лічильником, як `addLoan`. Додати тест на порожній або неповний рядок.
