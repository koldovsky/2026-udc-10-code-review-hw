- **Впевненість:** висока

### 2. [critical] [R3] Path traversal: ім'я файлу від клієнта без перевірки теки
- **Де:** `app/src/imports.js:18` (диф, рядок 39); параметр `uploadDir` — рядок 37
- **Цитата:** `const text = await readFile(path.join(uploadDir, fileName), "utf8");`
- **Чому це проблема:** `fileName` задає клієнт («ім'я, з яким його завантажили»). `path.join` не тримає результат у `uploadDir`. З дифом (тимчасова тека): `"../secret.txt"` прочитано поза `uploads/` і додано учасника `{"name":"TOP","email":"SECRET","phone":"VALUE"}`. Додатково `uploadDir` можна передати з виклику — публічний API дозволяє вказати будь-яку теку. Тести не містять жодного шкідливого імені.
- **Як виправити:** `const full = path.resolve(UPLOAD_DIR, fileName); const rel = path.relative(UPLOAD_DIR, full); if (rel.startsWith("..") || path.isAbsolute(rel)) throw …`; або приймати лише `path.basename(fileName) === fileName`; не приймати `uploadDir` з виклику; тести на `../x`, абсолютний шлях.
- **Впевненість:** висока

### 3. [high] [R15] `id: db.members.length + 1` дає дублікати id
- **Де:** `app/src/imports.js:23` (диф, рядок 44)
- **Цитата:** `db.members.push({ id: db.members.length + 1, name, email, phone, role: "member" });`
- **Чому це проблема:** щойно когось видалено (5 учасників з id 1–5, видалили id 2 → `length = 4`), новий учасник отримає id 5 — уже зайнятий. `findMember(5)` поверне іншу людину: картка, позики й журнал доступу прив'язуються до чужого запису.
- **Як виправити:** лічильник за зразком `nextLoanId`/`addLoan` або `Math.max(...ids) + 1`.
- **Впевненість:** висока

### 4. [low] [R15] Рядки CSV не валідуються
- **Де:** `app/src/imports.js:19-25` (диф, рядки 40–46)
- **Цитата:** `const [name, email, phone] = row.split(",");`
- **Чому це проблема:** рядок без email чи з меншою кількістю полів дає `undefined` у записі; дублікати email не відхиляються. Файл завантажує лише `admin` (довірена роль), наслідків для безпеки немає — тому low.
- **Як виправити:** перевіряти заголовок і кількість полів, `trim()`, формат email; повертати `{ added, rejected }`.
- **Впевненість:** висока
