# PR-6: Імпорт учасників із завантаженого CSV

Громада передає списки нових учасників файлом. Адміністратор завантажує CSV, файл кладеться в
`uploads/` під тим ім'ям, з яким його завантажили, і `importMembersFromUpload` додає людей. Модуль
згенеровано за специфікацією постачальника. Тест на звичайний файл додав.
